# アクセシビリティ

Planetariumは、星図を見たり直接クリックしたりできなくても、主要機能へ到達できることを目標にします。Canvasは説明的な表示であり、検索・一覧・詳細を操作の正本として併設します。

## 実装済み

| 要求 | Web | macOS |
| --- | --- | --- |
| Canvas以外の探索 | 検索可能なDOM一覧、等級・高度・方位 | 検索可能なSwiftUI一覧、インスペクタ |
| キーボード | スキップリンク、Tab順、検索shortcut、一覧のroving focus、3Dの矢印・`+`/`−`・Home、ダイアログの取消 | メニュー、検索・星移動・時刻・2D/3D・天球方向のshortcut |
| 読み上げ | 2D/3Dの説明、選択・軌跡状態、状態・エラー通知、同等のDOM一覧 | ネイティブコントロール、2D/3D天球の概要、選択・状態ラベル、天球の回転・選択custom action |
| 文字拡大 | 200%と390/195px幅で縦積み、3D密度抑制、横スクロールなし | `ViewThatFits`で時刻・再生操作を短い表示へ切替 |
| 色以外の意味 | 選択、地平線下、薄明を文字でも表示 | 選択、地平線下、薄明を文字でも表示し、「コントラストを上げる」時は線・選択・操作枠を強調 |
| 動き | 自動再生・camera自動回転なし、`prefers-reduced-motion`時は再生を無効化し±1時間を維持 | 自動再生なし、「動きを減らす」時は静止modeと手動時刻操作を維持 |

## 手動確認

1. ポインティングデバイスを使わず、地点、日時、時間再生、検索、星選択、2D/3D、天球回転・拡大縮小、設定、リセット、ヘルプを操作する。
2. Webを200%へ拡大し、390×844と最小幅195pxで横方向の欠落がないことを確認する。
3. VoiceOverで星一覧の名称、等級、高度、選択状態と、選択後の詳細を読み上げる。
4. 「コントラストを上げる」「視差効果を減らす」、Webのforced-colors/reduced-motionで情報が失われないことを確認する。
5. Canvasを無視しても同じ星を検索・選択でき、時間再生で選択星が一覧外へ移っても追跡状態と復帰導線が分かることを確認する。

## 既知の制約

- 全天図は多数の星を一つずつ読み上げない。代わりに名前付き恒星の一覧を提供する。
- 星の色と大きさは説明的表現であり、色覚や測光の厳密な代替情報ではない。
- forced-colors時もCanvas内部の物理色はsystem色へ置換せず、操作枠・選択・DOM情報をsystem色で補う。
- 3Dの実タッチgesture、OS強制カラー、VoiceOverの最終読み順は物理環境での確認が残る。
- macOSの最大アクセシビリティ文字サイズは、アプリを実行するMacがロック中のため、最新変更後の再撮影が残っている。
