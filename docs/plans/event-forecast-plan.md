# 食・掩蔽予報フェーズ実装計画

- 作成日: 2026-07-30
- 対象: Web版、macOS版
- 根拠: `docs/product/user-stories-events.md`
- 技術判断: `docs/decisions/0002-local-event-ephemeris.md`
- 状態: 実装中

## 完成像

既存の星図は起動時の軽さと操作を維持する。利用者が探索領域を「現象」へ
切り替えると、現在の観測日時を起点に、現在地点での日食、月食、月による
明るい恒星掩蔽を端末内で検索できる。選択した現象には局地可視性、接触時刻、
高度・方位、精度条件、安全注意を示し、明示操作で星図時刻へ移動・復帰できる。

## 実装順

1. **共有暦と再現性**
   - DE442sのURL、MD5、SHA-256、coverageを固定する。
   - SSB→EMB、SSB→Sun、EMB→Moonの係数を5年chunkへFloat32で抽出する。
   - manifest、schema、`--check`、raw/gzip budget、全境界の検証を追加する。
   - WebとSwiftのClenshaw評価を共有fixtureで照合する。

2. **有限距離天体パイプライン**
   - UTC／TT／TDB／UT1、光行時間、観測者位置・速度、歳差章動、地球回転、
     極運動を一つのbody-state APIへまとめる。
   - 太陽・月の中心方向、距離、角半径、高度・方位を返す。
   - 既存星用モデルへ影響させず、月表示とイベント計算だけで遅延利用する。

3. **候補索引と求根**
   - 新月・満月の粗い候補を生成時に索引化する。
   - bracketを失わないsafeguarded root solverと極小探索を両言語へ実装する。
   - 日食C1〜C4、月食P1〜P4／U1〜U4、掩蔽の潜入・出現をsigned clearanceで解く。
   - 接線、二重根、日跨ぎ、chunk境界、対応期間端を共有fixture化する。

4. **Web縦切り**
   - `React.lazy`で現象パネルと計算コードを分離する。
   - 監査済み同一origin asset loader、LRU、再試行、AbortSignal、stale結果破棄を実装する。
   - 「恒星｜現象」、一覧、詳細、接触操作、復帰、空・エラー状態を統合する。
   - 日食の安全注意と精度条件を常設する。

5. **macOS縦切り**
   - resource loaderとactor予報serviceを実装する。
   - SwiftUIの現象一覧・詳細・接触操作を既存navigationへ統合する。
   - MainActorへ重い探索を入れず、取消と非アクティブ停止を実装する。

6. **精度・性能・利用体験の反復**
   - JPL SPK、NASA/GSFC、JPL Horizons等の独立基準と比較する。
   - 初期転送、初回現象表示、メモリ、30日・1年検索時間を予算化する。
   - 1280×720、390×844、200%表示、キーボード、reduced-motion、
     forced-colors、Canvas代替情報を確認する。
   - 一般、観望、天文、開発、アクセシビリティ、無関心の各Mustを再監査する。

## 品質ゲート

- 元SPK hashが一致しない入力から生成しない。
- manifest外またはhash不一致のchunkを評価しない。
- 時刻の絶対値とJDをFloat32へ落とさない。
- 初期Webの既存予算を増やさない。
- イベントを開くまでイベント係数を取得しない。
- 予報失敗で星図を壊さない。
- 日食詳細から安全注意を隠さない。
- 両版の共有fixture差がイベント種別の許容差内に収まる。
- 平均月縁、EOP範囲外、地点精度不明を通常精度として表示しない。
