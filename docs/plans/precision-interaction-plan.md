# 精度・時間・3Dフェーズ実装計画

- 作成日: 2026-07-29
- 対象: Web版とmacOS版
- 根拠: `docs/product/user-stories-phase2.md`
- 状態: 実装・継続監査中

## 完成像

既定は従来どおり東京・現在時刻の2D全天図で、時間は停止している。利用者が
再生を開始すると、同じ観測日時をWeb/macOSの時計、2D、3D、一覧、詳細が
共有し、順方向・逆方向と複数速度で日周運動を確認できる。

恒星位置はBSC5Pの入力精度を超えて断言しない一方、単純な歳差だけではなく、
座標フレーム接続、空間運動、年周視差、太陽重力光偏向、年周光行差、IAU 2006歳差、
IAU 2000B章動、UT1恒星時、WGS84観測者の日周光行差、任意の可視光大気差を
順序付きで適用する。同梱IERS EOPからDUT1と極運動xp/ypを独立に補間し、
地球回転後のTIRS方向をITRSへ変換する。昼・薄明も旧UTC簡易式ではなく、
同じ地球姿勢と光行差を使い、水平位置だけWGS84観測地点の日周視差も加えた
太陽中心の幾何高度から判定する。見かけ赤経・赤緯は地心値として保持する。
既定近似と未適用補正はmetadata、ヘルプ、モデル文書から追跡できる。

3Dは観測者中心の単位天球であり、星の距離を表さない。2Dと選択・時刻を共有し、
WebGLが使えない場合は2Dへ戻る。自動回転は行わない。

## 実装順と品質ゲート

1. **精密星表と座標契約**
   - BSC5P v2へ固有運動、視差、視線速度を追加する。
   - J2000 FK5からHipparcos/ICRSへ位置・速度を接続する。
   - 正の視差がある星は距離を保持し、欠測した視線速度は0と明示して年周視差を可能にする。
   - schema、canonical hash、出典、品質上の注意を固定する。

2. **見かけ位置パイプライン**
   - UTC/TAI/TT/UT1、IAU 2006歳差、IAU 2000B章動、見かけ恒星時を実装する。
   - SOFA `epv00`の1,323項から世紀幅の寄与上限で100項を選んだ共有
     VSOP2000地球暦と解析微分速度を既定値にし、年周光行差・年周視差の
     外部ベクトル注入経路と分ける。
   - 年周視差後・年周光行差前に太陽重力光偏向を適用する。
   - 幾何高度と大気差適用高度を分離する。
   - 地球回転後・大気差前にWGS84観測者の日周光行差を適用し、
     楕円体高0 m仮定と明示的な無効化をmetadataへ残す。
   - IERS Finals 2000Aの日次xp/ypを4点補間し、TIO locator s′と
     SOFA `pom00`相当の極運動行列を日周光行差より前に適用する。
   - contextを深く不変にし、描画バッチで再利用する。

3. **独立数値検証**
   - 未改変SOFAの単体参照値、`fk52h → starpm`合成参照値、球面角距離を使う。
   - 極・天頂・地平線、1900/2100境界、欠測値、非有限入力を検査する。
   - 共有100項地球暦と未改変SOFA `epv00`を1900–2100の6時間刻み
     293,657時点で比較し、位置・速度・距離と光行差後の残差を文書化する。
   - SOFAの太陽位置8ケースで、地心の赤道方向とWGS84 topocenterの
     ENU方向を分離し、地球暦方向3秒角、距離`0.00001 AU`、
     全パイプライン5秒角未満を固定する。
   - 日周光行差をSOFA `pvtob`、`apio`、`atioq`から分離した共有fixtureで
     Web/Swift双方から検証する。

4. **観測時計**
   - 単調時間差を使い、停止、順逆、速度、境界停止、非表示停止を実装する。
   - reduced-motionでは再生を禁止し、手動の±1時間を残す。
   - 12Hzを上限の目安にし、背景復帰時の大きな時刻ジャンプを抑える。
   - 12Hzで変化する数値はlive regionへ入れず、低頻度の状態と仮定だけを
     `aria-live="polite"`で通知する。
   - 軌跡の非同期再計算は`status`にせず、checkboxの状態、凡例、
     Canvasの`aria-describedby`でオンデマンドに理解できるようにする。

5. **Web 3D天球**
   - Three.jsを操作時だけ読み込み、恒星は単一`Points`とtyped bufferで描く。
   - 2D Canvasと同じ純粋helperでdevice pixel ratioを1–2倍へ制限し、
     非有限値、0、負値は1倍へ戻す。
   - 地平面、地平線、北・東・南・西・天頂・天底、選択ring、
     回転・ズーム・リセットを提供する。
   - 6方向のDOMラベルをcamera quaternionへ追従させ、背面を減光し、
     天頂・天底の中心衝突を画面高に応じた14–28pxのoffsetで避ける。
   - 300px以下では回転4方向・reset・zoomを横一段にし、
     240pxでも天球中心と横scrollを塞がない。
   - 狭幅では等級限界を下げ、選択星は限界外でも残す。
   - 星座線、薄明背景、星名設定を2Dと整合させる。
   - 初期化失敗、context loss、chunk失敗から2Dへ復旧する。

6. **macOSネイティブ天球**
   - SwiftUI `Canvas`、trackball quaternion、ネイティブToolbar/Commands/Inspectorを使う。
   - dragとpinchに加え、常時見える方向・拡大縮小・向きと倍率のreset、
     menu shortcut、倍率の読み上げを提供する。
   - 2D/3D、再生、星座線、星名、ナイトモード、大気差を同じStoreへ集約する。
   - 「動きを減らす」、VoiceOver、大きな文字、ウインドウ狭幅で機能を失わない。

7. **タイポグラフィ**
   - WebはOFLの日本語書体を必要glyphだけWOFF2へ再現可能にsubsetする。
   - macOSはシステムフォントのrounded/monospaced digit等を用途別に使う。
   - ライセンス、生成スクリプト、CIでの再現性、初期転送予算を検証する。

8. **統合QAと反復**
   - 195×844、390×844、1280×720、200%、キーボード、高コントラストを確認する。
   - 再生中の2D/3D、選択同期、地平線通過、地点・日時変更、失敗復旧を確認する。
   - Web全テスト、本番build、予算、privacy、Cloudflare dry-run、Swift全テスト、
     `.app`署名・resource・起動検証を通す。
   - Web初期routeは12ファイル730.5KiB gzip以下を現行基準にし、
     最大初期JavaScript 600KiB raw、全JavaScript各720KiB rawのgateで
     単一chunkへの再結合を防ぐ。
   - 観察、変更、検証、残るリスクを改善ログへ追記する。

## 再監査後の実施順

開発者、一般利用者、天文学に詳しい利用者、アプリに関心のない利用者の
再監査では、新機能を増やす前に次の順で不足を閉じる。

1. 共有地球暦と太陽経路の再現性・誤差・配布契約を固定する。
2. 初回の空白を静的boot shellでなくし、読み込み前から目的と既定状態を伝える。
3. 1972年以前と既知うるう秒範囲後のTAI−UTC仮定を具体的な秒数で表示する。
4. 太陽方向とmacOS 3Dの回転・倍率を、専門知識やgestureなしでも操作・理解できるようにする。
5. 実配布、物理支援技術、実機PWAの未完了ゲートを残件として維持する。

## 明示する残差

- BSC5Pの座標・固有運動の格納精度と原カタログ注記が、内部式より先に精度を制限する。
- 既定地球位置・速度はSOFA `epv00`由来の共有100 / 1,323項による
  太陽中心地球状態であり、TTをTDBのproxyとして使う。SSB→太陽の位置・速度と
  地球中心→実観測地点の変位を含まないため、完全なBCRS観測者状態ではない。
- 同梱EOPの収録外・読込失敗時はDUT1=0秒、極運動xp/yp=0へ明示的に戻る。
  DUT1=0では地球回転角に最大約13.5秒角相当の差があり得る。
- 惑星光偏向、潮汐による日内極運動、地形、光害、減光はモデル外である。
  日周光行差は
  split-at-CIRS一次式で、既定地点はWGS84楕円体高0 mを仮定する。
- 標準大気差は高度5度未満へ外挿せず、境界に既知の段差がある。
