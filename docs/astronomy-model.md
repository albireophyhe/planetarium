# 天文計算モデル

- 版: 1
- 対応期間: 1900-01-01から2100-12-31
- 目的: 肉眼向け恒星図。測地・航法・望遠鏡制御には使用しない

## 用語と単位

- 時刻の内部表現: UTCのUnix秒
- 経度: 東経を正
- 緯度: 北緯を正
- 内部角度: ラジアン
- 方位角: 北を0、東回りに増加
- 恒星座標: J2000.0の平均赤経・赤緯
- 表示高度: 大気差を含まない幾何高度

画面でいう「地平線上」は幾何学的に高度が0度以上という意味です。肉眼で見えることを保証しません。昼光、薄明、天候、光害、地形、建物、視力は別の要因です。

## ユリウス日と恒星時

```text
JD = 2440587.5 + unixSeconds / 86400
T  = (JD - 2451545.0) / 36525

GMST degrees =
  280.46061837
  + 360.98564736629 × (JD - 2451545.0)
  + 0.000387933 × T²
  - T³ / 38710000

LST = GMST + longitude
```

UTCをUT1として近似します。

## 歳差

恒星のJ2000.0座標には、IAU 1976の簡略歳差式を適用して観測日の平均座標を求めます。固有運動、章動、年周光行差、年周視差は版1では省略します。高固有運動星や対象期間外では誤差が増えます。

## 地平座標

時角を`H = LST - RA`として、東・北・上向きの単位ベクトルを求めます。

```text
east  = -cos(dec) × sin(H)
north =  cos(lat) × sin(dec) - sin(lat) × cos(dec) × cos(H)
up    =  sin(lat) × sin(dec) + cos(lat) × cos(dec) × cos(H)

altitude = asin(clamp(up, -1, 1))
azimuth  = normalize0To2Pi(atan2(east, north))
```

## 太陽と薄明

太陽は低精度の平均太陽・黄経モデルから赤経・赤緯を求めます。目的は昼と薄明の分類であり、食や望遠鏡指向には使いません。

| 太陽高度 | 状態 |
| --- | --- |
| 0度以上 | 昼 |
| 0度未満、-6度以上 | 市民薄明 |
| -6度未満、-12度以上 | 航海薄明 |
| -12度未満、-18度以上 | 天文薄明 |
| -18度未満 | 夜 |

## 投影

天頂中心の正距方位図法を使います。

```text
R   = min(width, height) / 2 - padding
rho = R × (π/2 - altitude) / (π/2)
x   = centerX + rho × sin(azimuth)
y   = centerY - rho × cos(azimuth)
```

- 天頂は中央
- 地平線は外周
- 北は上
- 東は右
- 地平線下は星図に描画しない

この規約では東西を鏡像にしません。

## 精度とテスト

- SwiftとTypeScriptは同じJSONフィクスチャを読む。
- 主な合否は、二つの地平単位ベクトルの角距離で判定する。
- 天頂では方位角が不定になるため、方位角差だけを合否にしない。
- 基本恒等値はJ2000のユリウス日、GMST、天頂、東西地平、投影端点を含める。
- 実星ケースは東京、Greenwich、Sydney、赤道、高緯度と、Polaris、Sirius、Vega、Arcturusを含める。
- 地平線付近は大気差非対応のため、見かけ位置との差が最大およそ0.6度になる。

## 表現上の制約

星の大きさと色は見分けやすさのための説明的表現であり、測光的な輝度や肉眼の色知覚を忠実に再現するものではありません。星座線は文化的な結び方で、IAUが定める公式境界ではありません。
