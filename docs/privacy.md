# プライバシー

Planetariumは、観測地点と日時を既定では端末内の計算にだけ使用します。
任意の現在気象機能を明示的に使う場合の例外を以下に示します。

## 位置情報

- 起動時には位置情報を要求しません。
- 「現在地」を明示的に選んだ場合だけ、OSまたはブラウザの位置情報APIへ要求します。
- 拒否した場合も、都市プリセットと緯度・経度の手入力を利用できます。
- 正確な緯度・経度は既定で永続保存しません。
- 選択した座標や日時を起動時または位置選択時に外部APIへ送信しません。
- 大気差設定で「現在の気象を取得して適用」を明示的に選んだ場合だけ、
  気象庁の固定URLから全国の最新アメダスデータを取得します。気象庁には
  選択地点の緯度・経度を送らず、端末内で最寄りの適格な観測局を選びます。
- 気象庁実測を使えない場合だけ、選択地点の緯度・経度を小数4桁へ丸めて
  Open-Meteoへ送信します。日時、地点名、検索語、選択した星、OSが返した
  測位精度と高さは送信しません。

## 通信

Web版は、アプリ本体、星表、名称、星座線を同じ配信元から読み込みます。
外部フォント、解析SDK、天文APIは使用しません。Cloudflareへ公開した場合、
通常のHTTPアクセスに伴うIPアドレス等がCloudflareのログへ記録される可能性があります。

Web版とmacOS版の星図、星表、天文計算はネットワーク接続なしでも利用できます。
任意の現在気象機能だけは`https://www.jma.go.jp/bosai/amedas/`配下の固定URLへ
最新観測時刻、観測所表、全国観測mapを取得する匿名のHTTPS GETを行います。
観測所の選択は端末内で行うため、リクエストURLに利用者の座標は含まれません。
気象庁サイトには通常のアクセスに伴うIPアドレス、OS、ブラウザー、閲覧時刻、URL等が
記録され得ますが、アプリがGPS座標をqueryへ追加することはありません。

気象庁データが取得不能、古い、品質不良、または適格な観測局が25 km以内にない場合は、
`https://api.open-meteo.com/v1/forecast`へfallbackします。送信するのは小数4桁へ
丸めた緯度・経度と固定された気象変数指定だけです。Open-Meteoの無料サービスでは
IPアドレスと地理座標を含み得るサーバーログがトラブルシューティング目的で最長90日
保持されます。アプリ側では気象応答や座標を永続保存せず、解析、広告、追跡用通信を
行いません。

気象庁経路では、品質が良好で30分以内かつ25 km以内の最寄り局の現地気圧、気温、
相対湿度を使い、
観測局名、距離、標高、観測時刻を表示します。これはGPS座標上の端末センサー値では
ありません。気象庁公開データをアプリが最寄り局選択・湿度比変換したことと出典を
表示します。公開feedはversion付き開発者APIではなく、形式や提供継続の保証はありません。

Open-Meteo経路の現在条件は観測所センサーの生値ではなく、15分間隔の気象モデルを
もとにした値です。どちらの経路も、雲、視程、局地的な温度勾配は補正しません。
Open-MeteoデータはCC BY 4.0で、画面に`Weather data by Open-Meteo.com`と
ライセンスへの導線を表示します。無料APIは非商用利用かつ1日10,000回未満等の
上限があり、商用公開では有料API契約が必要です。

開発依存のinstall scriptは固定allowlist以外をhard failにします。同梱フォントの
`@ibm/plex-sans-jp`が持つtelemetry用postinstallは明示的に拒否し、
ビルドに必要な`esbuild`、`workerd`とmacOSファイル監視用`fsevents`だけを
完全なpackage名・versionで許可します。

## クリップボード

- 「参考座標をコピー」または「JSONをコピー」を明示的に選んだ場合だけ、
  選択星の座標、観測日時、入力または取得した緯度・経度・楕円体高、地点精度、
  time zone、EOPと大気差条件をシステムのクリップボードへ書き込みます。
- アプリ自身はコピー内容を外部へ送信せず、履歴や設定として永続保存しません。
- クリップボードはOSと他のアプリが共有し、環境によっては同期・履歴保存の
  対象になり得ます。地点を秘密にしたい場合は貼り付け先を確認し、利用後に
  別の内容で上書きしてください。

## 端末に保存する設定

- Web版は、正確な位置、日時、検索語、表示設定を既定では永続保存しません。
- Web版で手入力した気圧、気温、相対湿度、波長、適用下限高度は、
  タブを閉じるまでのメモリーにだけ保持し、外部へ送信しません。気象庁または
  Open-Meteoから取得した気象値も同じ扱いです。
- macOS版は、星座線、星名、ナイトモード、大気差のON/OFF、選択星の軌跡の
  5つだけを`UserDefaults`へ保存します。手入力または現在気象から取得した
  大気値と、その入力由来が手動であることは保存しません。次回起動時に大気差ONが復元される場合は
  標準大気へ戻ります。地点、緯度・経度、日時、検索語、選択した星は保存しません。
- macOS版の設定にある「保存した表示設定を消去」で、この5項目だけを削除できます。地点と日時は変更しません。
- 保存を利用できない環境でも、アプリの主要機能は動作します。
