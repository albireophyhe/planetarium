# プライバシー

Planetariumは、観測地点と日時を端末内の計算にだけ使用します。

## 位置情報

- 起動時には位置情報を要求しません。
- 「現在地」を明示的に選んだ場合だけ、OSまたはブラウザの位置情報APIへ要求します。
- 拒否した場合も、都市プリセットと緯度・経度の手入力を利用できます。
- 正確な緯度・経度は既定で永続保存しません。
- 選択した座標や日時を外部APIへ送信しません。

## 通信

Web版は、アプリ本体、星表、名称、星座線を同じ配信元から読み込みます。外部フォント、解析SDK、天文APIは使用しません。Cloudflareへ公開した場合、通常のHTTPアクセスに伴うIPアドレス等がCloudflareのログへ記録される可能性はありますが、アプリが選択地点の座標をリクエストへ追加することはありません。

macOS版は計算と星表の利用にネットワーク接続を必要としません。

開発依存のinstall scriptは固定allowlist以外をhard failにします。同梱フォントの
`@ibm/plex-sans-jp`が持つtelemetry用postinstallは明示的に拒否し、
ビルドに必要な`esbuild`、`workerd`とmacOSファイル監視用`fsevents`だけを
完全なpackage名・versionで許可します。

## クリップボード

- 「導入用データをコピー」または「JSONをコピー」を明示的に選んだ場合だけ、
  選択星の座標、観測日時、入力または取得した緯度・経度・楕円体高、地点精度、
  time zone、EOPと大気差条件をシステムのクリップボードへ書き込みます。
- アプリ自身はコピー内容を外部へ送信せず、履歴や設定として永続保存しません。
- クリップボードはOSと他のアプリが共有し、環境によっては同期・履歴保存の
  対象になり得ます。地点を秘密にしたい場合は貼り付け先を確認し、利用後に
  別の内容で上書きしてください。

## 端末に保存する設定

- Web版は、正確な位置、日時、検索語、表示設定を既定では永続保存しません。
- Web版で手入力した気圧、気温、相対湿度、波長、適用下限高度は、
  タブを閉じるまでのメモリーにだけ保持し、外部へ送信しません。
- macOS版は、星座線、星名、ナイトモード、大気差のON/OFF、選択星の軌跡の
  5つだけを`UserDefaults`へ保存します。手入力した大気値と、その入力由来が
  手動であることは保存しません。次回起動時に大気差ONが復元される場合は
  標準大気へ戻ります。地点、緯度・経度、日時、検索語、選択した星は保存しません。
- macOS版の設定にある「保存した表示設定を消去」で、この5項目だけを削除できます。地点と日時は変更しません。
- 保存を利用できない環境でも、アプリの主要機能は動作します。
