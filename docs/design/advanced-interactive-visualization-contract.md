# 高度インタラクティブ可視化契約 — 天球儀

## Approval And Evidence

- 承認済みコンセプト: `docs/design/planetarium-desktop.png`、`docs/design/planetarium-mobile.png`
- 大画面コンセプト: `docs/design/planetarium-desktop.png`
- モバイル縦コンセプト: `docs/design/planetarium-mobile.png`
- モバイル横: 3D検証用に844×390を追加する。縦向きの利用を妨げない。
- 承認根拠: 既存コンセプトを初回実装へ採用済み。利用者から「可能であれば3Dで天球を回す」追加要望あり。
- 一文の目的: 地平面の上下、方位、天球回転、選択天体の空間的位置関係を、全天図では隠れる奥行きを含めて理解する。
- 主な利用者: 一般の星空観察者、学習者、天文学に詳しい利用者。
- データ: 同梱のBright Star Catalogue v2。由来、ライセンス、更新方針は `shared/catalog/README.md` と `docs/astronomy-model-v2.md` に記録する。
- 測定／計算レイヤー: 星の位置、地平面、方位、天の赤道。
- 模式レイヤー: 球殻、観測者マーク、補助グリッド。星までの実距離は表現しない。
- 装飾レイヤー: 背景の弱い放射グラデーションのみ。
- 接続戦略: 全データをアプリへ同梱し、通常表示にネットワークを要求しない。
- 単位: 時刻は選択地点のIANAタイムゾーン、高度・方位は度、星位置は単位球。
- 真実不変条件:
  - 星の半径方向位置はすべて1であり、距離を意味しない。
  - 方位は北0°から東回り、高度は地平線0°から天頂+90°。
  - 地平線より下の星を「見える星」と誤認させない。
  - カメラ回転は観測時刻や計算済みの星位置を変更しない。
  - 星の大きさは見かけの等級の視認補助で、角直径ではない。
  - 位置精度の表示はカタログ、時刻尺度、モデルの限界を越えて主張しない。

## Renderer Ownership

- 主レンダラー: Three.js WebGL。8,404点の3D変換、直交カメラ、回転、選択を単一のGPUシーンで扱うため。
- フォールバック: WebGL初期化失敗、最初の有効フレーム失敗、コンテキスト損失時は既存Canvas 2D全天図へ戻す。
- WebGL: 星、球殻、地平線、方位グリッド、天の赤道。
- Canvas 2D: 2Dモード全体、および3Dの読み込み／障害時フォールバック。
- HTML: 表示切替、再生操作、凡例、選択天体の数値、状態、アクセシビリティ説明。
- SVG: 使用しない。操作アイコンは既存のLucide React。
- 重複禁止: 主表示は `2D | loading fallback | 3D` の排他的状態とし、3D初回フレーム後に2Dを背面へ残さない。
- render-ready: 正の描画寸法でWebGL rendererの初回描画が例外なく完了した時だけ
  `onReady`を一度通知し、それまでは2D loading fallbackを維持する。
- ライフサイクル: ResizeObserver、2D/3D共通DPR上限2、context lost/restored、Geometry/Material/Renderer/controlsのdisposeを実装する。
- 静止画: 画面キャプチャではDOM凡例と数値を含める。アプリ内エクスポートは今回の対象外。
- 描画境界: デスクトップは中央主面の`minmax(280px, 1fr)`行を満たし、
  モバイルは幅いっぱいの1:1表示、横向きは残りの高さへ収める。
- 電力予算: 常時アニメーションなし。時刻再生中、ドラッグ中、データ更新時だけ描画し、非表示タブと画面外で停止する。

## Coordinate Frames

| Layer | 座標系 | 変換の所有者 | 整合確認 |
| --- | --- | --- | --- |
| 星表 | J2000/FK5相当の赤経・赤緯と固有運動 | 精密天文ドメイン | SOFA参照ベクトル |
| 見かけ赤道座標 | 日付時点の章動・歳差・光行差適用座標 | 精密天文ドメイン | SOFA参照ベクトル |
| 地平座標 | 北0°・東90°・高度±90° | 精密天文ドメイン | 北極星、子午線、東西の既知ケース |
| Three.js単位球 | x=東、y=北、z=天頂 | 3Dアダプタ | 北・東・南・西・天頂・天底のラベル |
| カメラ | 球中心を見る直交投影 | 3Dシーン | リセット状態のスクリーンショット |
| ヒットテスト | CSSピクセルの最近傍点 | 3Dシーン | hover相当のプレビューとclick選択の一致 |
| HTML詳細 | 選択HRをキーにした共有状態 | React | 一覧、2D、3D、詳細の同期 |

- 投影: 遠近で等級や相対サイズを歪めない直交投影。
- 方位原点: 北。0°/360°を同一として正規化する。
- 高度: 球面上の緯度。垂直誇張なし。
- 最短回転: カメラ方位は等価角のうち最短経路を選ぶ。リセットは補間せず決定的に戻せる。

## Visual Encoding Ledger

| データまたは状態 | 視覚チャネル | 範囲 | 暗示してはいけないこと |
| --- | --- | --- | --- |
| 星位置 | 単位球上の位置 | 半径1 | 星までの距離 |
| 見かけの等級 | 点の直径と弱い明度 | 1.2–7 CSS px相当 | 角直径、物理半径 |
| B−V | 抑えた色温度 | 青白〜淡い橙 | 正確なRGB、実測スペクトル |
| 地平線上 | 通常の不透明度 | 0.68–1 | 肉眼で必ず見えること |
| 地平線下 | 低い不透明度と破線球殻 | 0.10–0.28 | 地面越しに観察できること |
| 選択 | 独立した細いシアン環 | 1状態 | 等級が高いこと |
| 再生中 | 再生ボタン、速度、時刻の状態 | 明示テキスト | 実時間であること |

- 色役割: 白〜暖色=星、シアン=選択とフォーカス、青灰=補助線、赤=ナイトモード。
- 優先度: 選択星 > 地平線上の明るい星 > 補助線 > 地平線下 > 球殻。
- グローは明るい星の探索補助に限定し、密度や不確実性を意味しない。
- hover必須情報は作らない。名称・高度・方位・等級は選択後のHTMLに常時表示する。
- モバイルでも選択名称、地平線上下、時刻、再生速度をhoverなしで確認できる。

## Shareability And Persistence

| 状態 | URL | 保存層 | 復元 |
| --- | --- | --- | --- |
| 2D/3D表示 | なし | localStorage v2 | 不正値は2D |
| 3Dカメラ | なし | セッションのみ | 既定カメラ |
| 再生速度 | なし | localStorage v2 | 60倍 |
| 再生中 | なし | 保存しない | 常に停止 |
| 時刻・地点・選択 | 今回はなし | 既存メモリ状態 | 既存既定値 |

- URL共有は今回の範囲外。将来導入時も再生中状態は含めない。
- URLが将来追加された場合はURLを保存状態より優先する。
- 既定値へ戻す操作はカメラ、レイヤー、検索、選択を戻すが、地点と観測時刻は保持する。
- 折りたたみ時も表示モード、選択天体、再生状態は外側で読める。

## Operational Workspace Shell

- シェル: 三面ワークスペース（検索／主表示／詳細）を狭幅で一列へ適応。
- コマンドバー: 地点、現在時刻、ヘルプ。
- ナビゲーション: 星検索と可視範囲。
- 制御レール: 主表示直上の2D／3D、直下のタイムライン。
- 中央: 2D全天図または3D天球儀のどちらか一つ。
- インスペクタ: 選択天体の高度、方位、等級、赤経、赤緯、モデル説明。
- 既定選択: 地平線上で最も高い名前付き星。存在しなければ未選択。
- 空面クリック: 選択を保持。ドラッグ: 3Dカメラ回転。誤操作で選択解除しない。
- モバイル: 主表示を最初に保ち、検索／設定は下部タブ。3D操作説明は短いオーバーレイから閉じられる。
- 同期: 一覧、2D点、3D点、詳細、前後選択は同じ `selectedHr` を使用する。

## Interaction State Machine

| 状態 | 入口 | 視覚反応 | 終了／再開 |
| --- | --- | --- | --- |
| default | 初期表示、リセット | 2D、停止、既定選択 | モード切替、再生、選択 |
| preview | ポインターが選択可能点へ近接 | カーソルと弱い輪郭 | pointerout、drag開始 |
| selected | 点、一覧、前後操作 | 選択環とHTML詳細 | 別の星を選択 |
| rotating | 3D空面をdrag | カメラのみ回転 | pointerupで確定 |
| playing | 再生または逆再生 | 時刻更新、速度と方向を表示 | 一時停止、非表示、境界 |
| fallback | WebGL失敗／損失 | 2Dと理由、再試行操作 | 明示再試行成功 |

- drag: 左ドラッグ／一本指で回転。右ドラッグや一指スクロール乗っ取りはしない。
- wheel/pinch: ポインターが3D面にある時だけズーム。ズーム±ボタンも提供。
- keyboard: 表示切替、再生、速度、リセット、星一覧は通常のフォーカス順。矢印回転ボタンでdragを代替。
- Escape: 操作説明を閉じる。選択は維持。
- タッチ: 3D面は `touch-action: none` を明示し、直前・直後にページスクロール可能な余白と操作ボタンを置く。
- タップ対象: 主要操作44px、その他最低24×24px。星の選択は最低16pxの見えない近傍半径と最近傍判定。
- センサー: AR、カメラ、端末姿勢、振動、通知は目的に不要なため使用しない。位置情報は既存の明示操作だけ。
- hover代替: tap、検索、前／次の星。
- idle: 常時回転しない。画面外、背景タブ、停止中は描画ループを止める。
- reduced motion: 初期停止。再生を押した場合も低頻度の離散更新とし、カメラ補間・慣性を無効化する。

## Domain Scene Contract

- 基盤: 半透明の天球殻、地平面、北東南西、天頂・天底。
- ラベル: HTMLで選択名称と状態、シーン内は北東南西と天頂・天底のみ。密集星名をGPU面へ置かない。
- 物理モデル: 星は無限遠方向を単位球へ正規化した模式図。地平面と座標方向は厳密、球半径と星サイズは説明用。
- 適応: 小画面では補助グリッドと地平線下の点密度を減らすが、選択星と方位は維持する。
- データ欠落: 固有運動等の欠測は0として扱い、モデルメタデータへ件数を出す。位置そのものが欠ける行は描画しない。

## QA Checklist

- Build/type/lint: `npm run web:check`
- 全体品質: `npm run check`
- デスクトップ: 1280×720以上で2D、3D、再生、選択を撮影。
- モバイル縦: 390×844、360×800、430×932。
- モバイル横: 844×390。
- WebGL: 初回非空、点バッファ件数、render-ready、context lossから2D復帰。
- フォールバック: WebGLを無効化したスクリーンショット。
- 操作: drag、wheel、pinch相当、ズームボタン、回転ボタン、リセット、2D/3D切替、点選択、一覧選択。
- 同期: 選択、時刻、地点、レイヤーが両表示と詳細で一致する。
- モバイル: 一指操作後もページスクロールへ戻れる。検索キーボードを閉じた後に主表示へ戻れる。
- 座標: 北・東・南・西・天頂・天底、地平線直上／直下、日付変更前後。
- 精度: SOFA由来の独立ベクトルとカタログ固有運動の既知ケース。
- アクセシビリティ: キーボード、スクリーンリーダー向け要約、縮小動作、200%ズーム、強制カラー。
- 既知の逸脱: 3Dは距離を表さず、星間の奥行き比較には使えないことを画面とヘルプへ記す。
