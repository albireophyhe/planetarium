# Planetarium デザイン仕様

## 採用コンセプト

- デスクトップ: `docs/design/planetarium-desktop.png`（1536×1024）
- モバイル: `docs/design/planetarium-mobile.png`（853×1843）

二つの画像はレイアウト、密度、配色、状態表現の仕様です。星図内の星は画像アセットにせず、実際の星表からCanvas／SwiftUI Canvasで描画します。

## ビジュアルの考え方

主役は一つの大きな全天円です。周囲の操作は、空を塞がない細いツールバー、時刻レール、一覧、インスペクタに限定します。装飾カードを重ねず、線、余白、わずかな面の差で階層を作ります。

Webでは偽のmacOSウインドウボタンを描きません。コンセプト左上の三色ボタンはネイティブMacウインドウのクロームを示すもので、macOS版ではOSが提供し、Web版では省略します。

## タイポグラフィ

- Web: `IBM Plex Sans JP 3.0.0`のRegular 400／SemiBold 600から、Webソースと同梱星表に現れる文字をサブセットし、OFLのReserved Font Name条件に従って`Planetarium Sans JP`へ改名した自己ホスト書体。読み込み前、利用者入力、原書体に未収録の`U+1D45 MODIFIER LETTER SMALL ALPHA`と`U+2212 MINUS SIGN`は端末書体へフォールバックする。外部フォントサービスへ通信しない。
- Webの時刻・座標: `SFMono-Regular`等の端末内等幅書体を優先し、`tabular-nums`を併用する。
- macOS: SwiftUIのネイティブ書体を基礎に、ブランド／見出しはrounded design、時刻・座標はmonospaced digits、本文は標準designへ役割分担する。
- 原書体IBM Plex Sans JPはSIL Open Font License 1.1。Python 3.12.3と`script/requirements-fonts.txt`の固定依存で`script/subset_fonts.py`を実行し、`--check`で同じバイト列、文字カバレッジ、name table、ライセンスレコード、weight class、WOFF2予算を検証する。配布上の通知は`THIRD_PARTY_NOTICES.md`へ記録する。
- アプリ名: 20–24px相当、semibold
- 選択天体: 28–34px相当、bold
- 主要値: 30–38px相当、regularまたはmedium、tabular digits
- 本文・行: 15–17px相当
- 補助・単位: 12–14px相当。ただしモバイルで12px未満にしない
- コントロールの文字サイズは明示し、ブラウザ既定値へ委ねない

## 間隔と形

- 基本間隔: 4, 8, 12, 16, 24, 32px
- 主要外周余白: デスクトップ24px、モバイル16px
- コントロール高さ: 40–44px、モバイル44px以上
- 入力、セグメント、パネル半径: 8–12px
- 巨大な丸角コンテナや多重カードは作らない
- 境界は原則1px、選択とフォーカスだけ2px

## デスクトップ

- 上部ツールバー: 高さ56px前後
- 主領域: 星図68%、一覧・詳細32%
- 全天円: 利用可能な高さと幅の小さい方へ収め、四方位を切らない
- 時刻レール: 星図列の下端に一列
- 一覧: 検索、地平線上／すべて、星の行
- 詳細: 名称、三つの主要値、折りたたみ詳細
- レイヤー: 星座線、星名、ナイトモード

macOS版はこの構造を`NavigationSplitView`のdetailとinspectorに適応します。Web版はCSS Gridで同じ比率を作ります。

## モバイル

- ツールバー、観測時刻、切れない全天円、薄明、時刻操作の順
- その後に「星を探す／表示設定」の二タブ
- 星の一覧と詳細は縦へ続く
- 横スクロールを発生させない
- 390 CSS px、200%ズームで主要操作を維持する

最初のビューポートで使用する主なコピーは次に限定します。

- `Planetarium`

- `現在地`
- `ヘルプ`
- `星を検索`
- `地平線上`
- `すべて`
- 星の固有名
- `高度`
- `方位`
- `等級`
- `詳しい情報`
- `星座線`
- `星の名前`
- `ナイトモード`
- 薄明区分
- `地平線上の星を表示しています`

エラー、位置許諾、入力編集、ヘルプ内では、機能上必要な説明を追加できます。

## アイコン

- 地点: pin
- 現在地: location arrow
- ヘルプ: question mark circle
- 検索: magnifying glass
- 時刻: calendar / clock
- リセット: counter-clockwise arrow
- 詳細: chevron

Webは同じ線幅の小さなSVGを使い、SwiftUIは対応するSF Symbolsを使います。星の選択記号は文字の`★`を操作ラベルの代わりにせず、Canvas上の円と一覧行の選択境界で表現します。

アプリアイコンは濃紺の全天図、方位軸、4つの星を共通意匠とし、Webは
`favicon.svg`、macOSは同じ原画から10解像度を収録した`Planetarium.icns`を
配布します。原画とICNSのSHA-256、10表現、librsvg 2.62.3でのbyte再現は
`script/build_app_icon.sh --check`と`--reproduce`で検証します。

## 動き

- 選択は120–180msの色・境界変化だけにする。
- 星空は日時または地点が変わった時に再描画する。
- 自動回転や常時きらめくアニメーションは行わない。
- `prefers-reduced-motion`／macOSの視差効果を減らす設定では補間を無効にする。
