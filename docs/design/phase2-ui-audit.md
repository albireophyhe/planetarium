# フェーズ2 UI監査

## 監査条件

- 実施日: 2026-07-29
- 対象: Web版の既存実装（改修前）
- デスクトップ証跡: [phase2-baseline-desktop.jpg](evidence/phase2-baseline-desktop.jpg)
- モバイル証跡: [phase2-baseline-mobile-390x844.jpg](evidence/phase2-baseline-mobile-390x844.jpg)
- モバイル表示幅: 390 CSS px
- 比較対象: `docs/design/planetarium-desktop.png`、`docs/design/planetarium-mobile.png`

## 維持する長所

- 全天星図、時刻、検索、詳細を一画面にまとめた情報構造は明快。
- 検索結果と星図の選択が同期し、Canvasが使えなくても一覧を利用できる。
- 暗い背景、細い境界、星の明度差という既存の表現は主題を邪魔しない。
- キーボードフォーカス、ライブ通知、モバイル用タブ、強制カラーモードの基礎がある。

## 優先度付き所見

### P0 — 390pxで横方向に大きく欠ける

ヘッダーの `auto + minmax(110px, 1fr) + auto` と長いブランド名、地点、現在地操作の最小幅が競合し、ページ自体の最小内容幅が表示幅を超える。星図、日時、操作列も同じ広がった幅を引き継ぐため、主要体験が画面外へ切れる。`overflow-x: hidden` は原因を隠すだけで、利用可能にはしない。

対応:

- 560px以下ではブランド、地点、主要アクションを二段ではなく「短いブランド + 地点 + アイコン操作」に再構成する。
- すべてのグリッド子へ `min-width: 0` を徹底し、Canvasの測定元がビューポート幅を越えないようにする。
- 日時入力、再生操作、速度選択を狭幅専用の複数行レイアウトにする。
- 360px、390px、430pxと200%ズームで横スクロールがないことを自動・目視確認する。

### P0 — 時間を「動かす」状態が存在しない

日時入力と±1時間は離散操作だけで、星の移動を連続的に観察できない。再生中か、どの方向・倍率で進んでいるかも表現できない。

対応:

- 再生／一時停止、逆再生、速度プリセット、前後ステップ、現在時刻復帰を一つのタイムライン状態機械で管理する。
- 再生状態と観測日時を常時表示し、背景タブ・画面外・省電力相当では描画を停止する。
- `prefers-reduced-motion` では自動再生せず、離散ステップを完全な代替経路にする。

### P1 — 2Dと将来の3Dの役割が区別されていない

現在の全天図は方位・高度を読むのに適する。一方で天球の裏側、天の赤道、地平面との空間関係は示せない。3Dを同じ見た目の別表示として足すだけでは、操作負荷だけが増える。

対応:

- 「全天図」は正確な方位・高度の読み取り、「天球儀」は地平面の上下と天球回転の理解という役割を明記する。
- 表示切替を星図直上の二択に置き、検索、選択、日時、地点、表示設定を共有する。
- 3Dでも選択天体の高度・方位はHTMLの詳細欄に表示し、ドラッグできない利用者向けに回転ボタンとリセットを用意する。

### P1 — タイポグラフィの役割分担が弱い

本文、日時、座標、ブランドが同じシステム書体と近い太さで、数値を追う画面としてのリズムが平坦。Canvas内だけ別のハードコードされたシステム書体を使うため、UIとの統一も崩れる。

対応:

- 日本語とラテン文字を一貫して扱える情報設計向け書体を自己ホストし、ライセンスを同梱する。
- 本文／操作、見出し、時刻・座標の三役をトークン化する。日時と座標は等幅または表幅数字を使う。
- CJKは同じ行高のままラテン基準の95%を目安に調整し、12px未満の可視文字を作らない。
- CanvasへCSSの計算済みフォントを渡し、UIと星図ラベルの書体を揃える。

### P1 — 精度の説明が「幾何学的」だけで判断材料に乏しい

現在の文言は屈折を含まないことは示唆するが、歳差章動、固有運動、UTC/UT1、カタログの時代といった制約を判断できない。専門利用者には精度の根拠が不足し、一般利用者には用語だけが残る。

対応:

- 画面上は「見かけの位置／幾何位置」の短い状態表示に留める。
- 詳細またはヘルプに、使用モデル、入力の既定値、カタログ由来の支配的誤差、対応期間を開示する。
- 大気差は明示的な設定とし、地平線付近では適用条件を示す。

### P2 — 主要面の階層は保てるが、境界が均質

すべての入力、一覧、詳細が同程度の青い境界を持ち、選択、入力、単なる区切りの優先度差が弱い。

対応:

- 通常境界をさらに抑え、フォーカス、選択、再生中だけアクセントを使う。
- 星図と時刻レールを一つの観測ワークベンチとしてまとめ、右側は検索と詳細の二階層にする。
- 装飾カードやグローは増やさず、余白、文字サイズ、表面色の差で階層を作る。

## 受け入れ基準

- 390×844で北・東・南・西を含む全天円と主要時刻操作が欠けず、横スクロールがない。
- 2D／3Dを切り替えても日時、地点、選択天体が維持される。
- 再生、逆再生、一時停止、速度変更、±1時間、現在時刻復帰が同じ時刻状態を更新する。
- 3Dが利用できない場合も2Dへ自動復帰し、検索・数値確認・時刻操作を継続できる。
- 360px以上で主要タップ対象は44pxを目標にし、最低でもWCAG 2.2の24px要件を下回らない。
- 通常、キーボード、タッチ、縮小動作、高コントラスト、WebGLコンテキスト損失を確認する。
