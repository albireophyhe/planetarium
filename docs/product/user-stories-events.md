# 食・掩蔽予報フェーズのユーザーストーリー

- 評価日: 2026-07-30
- 対象: Web版、macOS版
- 優先順: 正しさ、安全性、一般利用価値、軽量性、両版の再現性

## 優先範囲

Mustは日食、月食、月による同梱の明るい恒星の掩蔽とする。月による惑星掩蔽、
接食、世界経路図、ICS/CSV出力はShould、小惑星掩蔽、通知、観測報告はCouldと
する。

現行の起動画面、既定2D、停止状態、位置権限を求めない挙動は変えない。
イベント機能は探索領域の「恒星｜現象」切替から明示的に開き、その時だけ
高精度暦と予報コードを読み込む。

## Must

| ID | 視点 | ストーリー | 受け入れ条件 |
| --- | --- | --- | --- |
| E-M1 | 一般 | 今後この場所で起きる主要現象を知りたい | 「現象」へ切り替えると、検索起点、地点、種類、現地日付、計算上の可視性、最大時高度を持つ一覧が出る |
| E-M2 | 一般 | いつ、どちらを見ればよいか知りたい | 詳細に現地時刻、タイムゾーン、UTC、高度、方位、地平線状態を示す |
| E-M3 | 観望 | 接触時刻へ正確に移動したい | 接触と最大をボタンで選べ、再生を停止して移動し、「元の日時に戻る」で復帰できる |
| E-M4 | 観望 | 境界付近を断定されたくない | 地点精度を判定へ伝播し、境界付近は「不確実性あり」と理由を返す |
| E-M5 | 観望 | 昇没で一部しか見えないことを知りたい | 各接触に地平線上／下を持ち、見えない段階と理由を省略しない |
| E-M6 | 天文 | 予報を再現したい | 暦、EOP、Delta T、月半径・月縁モデル、観測者高、データ版、hashへ到達できる |
| E-M7 | 天文 | 表示桁を精度保証と誤認したくない | 時刻・角度・経路の誤差、未評価要因、最大寄与要因を示し、根拠のない信頼度%を使わない |
| E-M8 | 開発 | 両版を同じ根拠で検証したい | 同一イベントID、UTC接触、可視状態、警告、共有fixtureと種別ごとの許容差を使う |
| E-M9 | 開発 | 軽さを維持したい | 初期Web予算を増やさず、現象を選んだ時だけUI、候補索引、暦chunkを遅延読込する |
| E-M10 | 開発 | 長い探索でUIを止めたくない | 検索はキャンセル可能で、地点・期間変更後の古い結果を捨て、非表示時に停止する |
| E-M11 | アクセシビリティ | 図を見ずに予報を使いたい | 一覧、接触時刻、可視状態、不確かさをDOM／SwiftUIの構造化された項目で取得できる |
| E-M12 | アクセシビリティ | 動きや通知で妨げられたくない | 自動再生なし、reduced-motionでも接触操作が使え、完了通知は一度だけ`polite`で行う |
| E-M13 | プライバシー | 精密地点を送信・保存せず使いたい | 計算は端末内で、座標・標高・期間・選択を既定保存せず、権限は明示操作時だけ求める |
| E-M14 | 安全 | 日食を危険な方法で観察したくない | 日食詳細に常設の文章による注意を置き、通常のサングラスや未濾過光学機器を安全と案内しない |
| E-M15 | 無関心 | 現象機能に邪魔されたくない | 起動時の画面、音、通知、権限、初期転送量を変えない |
| E-M16 | 堅牢性 | 予報だけ失敗しても星図を使いたい | イベント領域だけに理由と再試行を出し、星図、地点、日時、恒星選択を保持する |
| E-M17 | クロスプラットフォーム | MacとWebで同じ判断を得たい | 主要項目、文言、イベント状態、接触選択を揃え、UI部品だけOSへ合わせる |
| E-M18 | 一般 | 相対配置図の時刻を現在の星図時刻と取り違えたくない | 解いた接触・最大／最接近と、任意UTCの物理sampleを区別して表示する。図と星図の時刻が同じか別かを常に示し、「選択時刻を空に表示」で再生を停止して両者を揃える |
| E-M19 | 天文 | 接触間の動きを見ても補間値を物理計算と誤認したくない | scrub／再生の各表示フレームをDE442s・EOP・地点・星表から指定UTCで再計算し、画面座標を補間しない。全経過で角度縮尺を固定し、平均月縁などのmodel限界を維持する |
| E-M20 | 開発 | 連続表示を開いても年間予報cacheを肥大化させたくない | 暦providerとEOP snapshotを選択中イベント1件のsessionだけが保持し、年次LRUにはclosureを保存しない。session変更は取消可能で、時刻sample cacheには上限がある |

## Should

- 種類、期間、「地平線上の段階があるもの」のフィルター
- 観測者標高と地点の水平精度の入力・表示
- 暗縁／明縁、位置角、接食距離、月縁モデル
- 世界経路図を独立した遅延chunkとして表示
- 正確な地点を既定で含めないICS／CSV出力
- 200%表示、forced-colors、VoiceOverの実機確認

## 実装後レビューによる再優先付け

初回実装を実データで操作した結果、次のShouldをMust相当へ引き上げて実装した。

- 種類フィルターをWebのnative selectとmacOSのnative Pickerで提供し、
  `すべて／日食／月食／恒星掩蔽`を同じ順序と名称にする。
- 地平線下の件数と切り替えを、現在選択している種類だけにスコープする。
- 予報年を観測地点の現地日付で区切り、その基準を画面に明示する。
- 種類変更後も選択対象が残る場合は維持し、外れた場合だけ先頭へ移し、
  0件なら選択を解除して理由別の空状態を示す。
- 月縁地形を使わない日食は、NASAの実月縁偏差に基づく±6 kmを基礎境界幅とし、
  外食・中心食境界付近では接触や分類を断定しない。
- 物理境界の不確実性と地平線上／下を独立した状態として示し、境界付近という
  理由だけで「見える現象」へ分類しない。
- 1900年／2100年にイベント暦の安全な受信時刻範囲が現地年を覆い切らない
  地点では、欠落時間を「現象なし」とせず収録範囲の注意として示す。
- Webの構造化listboxと一度だけの`polite`通知、macOSのnative Pickerと
  Announcement、接触時刻から復帰した後のfocusを両版の操作契約に含める。
- 同時に始まるMacのresource読込を共有し、取消された待機側が他の読込を
  破棄しない。Web／MacともA→B→Aの年再訪で同じassetを再読込しないことを
  benchmarkで監査し、同じ地点・年の直近3結果はsolver再実行なしで復元する。
- 観測年を開いた時は、種類と地平線filter後の局地最大時刻を基準に、観測日時
  以後の最初の現象を選ぶ。全件が過去なら最新、別年なら時系列先頭を選ぶ。
- 明示的な現在地取得では精度を優先した一回取得を行い、OSが返した水平精度を
  日食・掩蔽の境界判定と再現情報へ伝える。都市・手入力の精度は捏造しない。
- 太陽・月・地球影・対象星の中心間角度と角半径を同じ尺度で描く相対配置図を
  提供する。solver済み時刻の正確なjumpに加え、最初と最後の確定接触間を
  任意UTCで物理再計算するscrubと、明示開始の概要再生を提供する。

次のShouldは意図的に残す。これらは軽量な年間一覧よりデータ量または専門性が
大きく、別の遅延機能として設計する。

- 任意の開始・終了日による期間検索（現在は現地年単位）
- 観測者標高と地点水平精度の直接入力
- LRO／かぐや等の月縁地形を使う接食専用局所図
- 世界経路図と位置を伏せたICS／CSV出力
- 物理VoiceOver、PWA、最大文字サイズの配布候補実機確認

接触位置角は日食・月食・恒星掩蔽へ実装済みで、CIRS接平面の天の北を
0°として東回りに表示する。平均球形月縁のため、Baily's beadsや局所月縁地形の
接触点を表すものではない。

## Could

- 更新日の短い小惑星掩蔽データ
- 通知とカレンダー登録
- 複数観測地の比較
- 経路共有
- 観測結果の記録・報告

## 情報・操作モデル

- Webの`side-panel`とmacOSの`StarSidebarView`に「恒星｜現象」を置く。
- モバイルは既存の「星を探す｜表示設定」を維持し、「星を探す」内で切り替える。
- イベントを選んだだけでは観測日時を変更しない。
- 「最大時刻を空に表示」を明示操作にし、選ぶと再生を停止する。
- 相対配置のselectorとscrubber自体は図の時刻だけを切り替え、観測日時を変更しない。
- 「選択時刻を空に表示」を明示操作した時だけ再生を停止し、星図と静止図を
  同じUTCへ揃える。
- 星図時刻が選択した図の時刻から離れた場合も図を勝手に動かさず、
  「現在の星図時刻とは別」と明示する。
- 接触間の配置を画面座標で補間せず、任意時刻は物理状態を再計算する。
- 連続再生は明示操作でだけ開始し、非表示化とreduced-motionでは停止する。
  手動scrubと計算済み時刻の選択は引き続き利用できる。
- 時刻操作の近くに接触時刻と「元の日時に戻る」を表示する。
- 地点変更時は同じイベントを再計算し、見えない場合も理由を表示する。
- 全天図の太陽・月円盤は誇張しない。接触形状は角尺度付きの局所図へ分ける。

詳細の順序は、平易な名称、局地可視性、最大時刻、方向、主操作、接触表、
安全注意、精度と条件、再現情報とする。

## 状態契約

| 状態 | 表示と復旧 |
| --- | --- |
| 期間内に現象なし | 「この期間にはありません」と期間を広げる操作 |
| 現象はあるが地点から見えない | 理由と「全現象を見る」または地点変更 |
| 一部だけ地平線上 | 接触ごとに状態を表示 |
| 境界付近 | 断定せず、地点精度と正確な入力方法を案内 |
| EOP・暦が範囲外 | 黙って0近似へ落とさず「参考計算」へ降格 |
| データ読込失敗 | イベント領域だけに再試行 |
| 再計算中 | 旧結果を以前の地点の結果と明示し、新旧を混ぜない |
| 地点権限拒否 | 都市と手入力をその場に提示 |
| WebGL失敗 | DOM詳細と2D星図を維持 |
