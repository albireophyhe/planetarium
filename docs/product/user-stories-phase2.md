# 精度・時間・3Dフェーズのユーザーストーリー

- 評価日: 2026-07-29
- 対象: 初回MVP後の継続改善
- 判定基準: 正しさ、学習価値、操作頻度、誤解時の影響、両プラットフォームでの実現性

## 優先順位を変えた発見

初回MVPは「指定地点・日時の星空を探す」用途を満たした。一方、時間を動かして
日周運動を理解する用途では、単純なJ2000歳差だけでなく、入力星表の座標系、
固有運動、時刻系、章動、光行差、視差を区別し、計算中の近似を画面から確認
できる必要がある。

3Dは装飾ではなく、地平線の上下、天頂・天底、星空全体の回転方向を理解する
補助表示として扱う。2D全天図を置き換えず、WebGLが使えない場合も主要操作を
失わせない。

## 現行コードからの再優先度監査

「実装済み」はコードと自動検証が揃った範囲、「一部完了」はplatform差または
実機・配布ゲートが残る範囲を指す。

| 視点 | 今回優先したストーリー | 判定 | 根拠と残件 |
| --- | --- | --- | --- |
| 開発者 | 地球暦・太陽経路・初期HTMLを再現可能な配布契約にしたい | 実装済み | VSOP2000由来200項のgenerator/schema/hash/両bundle検査、地心赤道方向とWGS84 topocenterを分けるSOFA 8件fixture、CSP互換boot shellのstylesheet参照・byte一致・inline禁止検査を追加 |
| 一般ユーザー | 待機中も何のアプリか分かり、太陽の方向と3Dの向きを迷わず確認したい | 実装済み | Web boot shell、両版の太陽マーカー、macOS 3Dの6方向ラベル・方向・75–250%倍率・reset・shortcutを自動テストとbundle起動で確認 |
| 天文学に詳しいユーザー | 暦の切り詰めと時刻系の仮定を具体値で見たい | 実装済み | VSOP100の選択規則・全期間残差を文書化し、Web/macOSとも1900年の0秒近似と将来の37秒仮定を通常期間では出さない警告として表示。macOSはInspectorから根拠の詳細も確認できる |
| その他・無関係な人 | 開いただけで待たされる理由が分かり、操作を強制されたくない | 実装済み | 起動前シェルは目的と準備状態の2文だけに抑え、既定2D・停止、音・自動回転・位置権限・強制チュートリアルなしを維持 |

この監査により、追加天体や共有URLより先に、起動時の理解、具体的な時刻系警告、
太陽方向、gestureに依存しないmacOS 3Dナビゲーションを優先し、実装を完了した。
公開配布と物理VoiceOver/PWAは、実装とは分けたリリース残件として扱う。

## Should

| ID | 視点 | ストーリー | 受け入れ条件 |
| --- | --- | --- | --- |
| P2-G4 | 一般 | 選択した星が沈んでも追跡を見失いたくない | 選択を保持し、地平線上フィルタから外れた理由と「すべて」への導線を示す |
| P2-A5 | 天文 | 年周視差の適用可否を星ごとに知りたい | 正の視差値、欠測、無効化、近似暦、外部BCRS観測者位置を別modeで返す |
| P2-A6 | 天文 | より正確なEOPや暦を差し替えたい | DUT1、極運動xp/yp、TAI−UTC、観測者位置・速度、WGS84楕円体高を公開オプションとして注入できる |
| P2-D4 | 開発者 | UTC日境界でも一時的な近似frameを描画・コピーしたくない | 次の日のEOPを準備してから観測日時・星位置・時刻系・EOPを同一frameとして公開し、収録期間内の日跨ぎでDUT1=0・xp/yp=0へ一瞬も降格しない |
| P2-A8 | 天文 | 機材が要求する座標系を取り違えたくない | J2000、地心見かけ、真空topocentric、観測topocentric、診断情報をprofile IDとschema version付きpayloadで区別し、frame・origin・epoch/equinox・単位・大気差を機械可読にする |
| P2-A9 | 天文 | 実際の気象に合わせた大気差を比較したい | 気圧・気温・湿度・波長と入力由来を保持し、真空座標を常に併記する |
| P2-E2 | 教育 | 時間変化を静止状態でも比較したい | 選択星だけを前後3時間・30分間隔・最大13点で示す既定OFFの軌跡レイヤーを2D/3Dへ同期する |
| P2-E3 | 教育 | 3Dでも星座の形を追いたい | 2Dと同じ星座線を球面上へ描き、地平線下・背面を弱く表示する |
| P2-X3 | アクセシビリティ | 高コントラストでも操作箇所を判別したい | forced-colors、prefers-contrast、明瞭なfocus、44px相当の主要ターゲットを確認する |

P2-A8は継続監査で実装済みである。WebとmacOSは共通の
`planetarium.precision-pointing.full-v1`と`schemaVersion: 1`を持つ
JSON profileを明示操作でコピーし、J2000、地心見かけ、真空topocentric、
観測topocentricをframe・origin・単位・方位規約と共に区別する。
利用できない精密値は`null`と状態で表し、適用したEOPが0近似の場合だけ
`0`と`assumed-zero`を組み合わせる。これは転記・再現の契約であり、
表示桁やJSON化による精度保証ではない。

## 今回は行わない

- 全恒星の実距離を半径にした銀河3D表示。現在の3Dは方向を示す天球である。
- オンライン星表・EOPの暗黙取得。オフライン計算と再現性を優先する。
- 望遠鏡の無人自動導入、測地、航法。食・掩蔽は後続の独立フェーズで
  参考予報として実装し、このフェーズの恒星位置精度とは別に検証する。
- 自動再生、自動カメラ回転、強制チュートリアル。
